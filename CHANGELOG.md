# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [0.1.0] - 2025-01-24

### Added
- **Project Foundation**: Set up the complete repository structure for modern-css-components.
- **Repository Guidelines**: Created `LICENSE` (MIT), `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, and `ROADMAP.md`.
- **Primary Documentation**: Added introductory guides in the `docs/` folder:
  - `getting-started.md`
  - `accessibility.md`
  - `coding-standards.md`
  - `browser-support.md`
- **Component Template**: Added `COMPONENT_TEMPLATE.md` under `docs/` to standardize the creation of future components.
- **Component Placeholders**: Configured 20 official component categories under `components/`, each featuring an educational `README.md` outline:
  - `buttons`, `cards`, `forms`, `navigation`, `heroes`, `footers`, `pricing`, `alerts`, `badges`, `avatars`, `tables`, `accordions`, `tabs`, `modals`, `tooltips`, `breadcrumbs`, `pagination`, `progress`, `loaders`, and `utilities`.
- **Assets & Examples**: Established root folders for `assets/` and `examples/` with dedicated usage documentation.
