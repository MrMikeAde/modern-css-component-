# Assets Directory

This directory stores all global visual and media assets used in repository documentation, standard mockups, and component preview structures.

---

## Guidelines for Asset Contributions
1. **Optimize Vectors**: When adding SVG diagrams or component illustrations, ensure they are fully minified and do not contain embedded raster code or redundant elements.
2. **Compress Images**: Any screenshots, mockups, or previews (such as PNG/JPEG/WebP) should be compressed to keep repository checkouts lightweight.
3. **Semantic Directories**: Place assets into descriptive subfolders (e.g. `assets/icons/`, `assets/brand/`, `assets/previews/`).
