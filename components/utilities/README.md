# Utilities Category

## Overview
Utility classes provide reusable, single-purpose styles that help speed up layout construction. Rather than loading heavy helper libraries, this category provides clean, modular CSS utility classes focused on standard layouts, responsive grids, aspect-ratios, and accessibility helpers.

## Planned Components
1. **Screen-Reader Only (`.sr-only`)**: An essential class to hide element text visually while keeping it fully readable by assistive screen readers.
2. **Container Boundaries**: Fluid page-width wrappers that limit content span and keep layouts centered.
3. **Aspect Ratio Helpers**: Utilities that lock element proportions (e.g., videos or photos) natively.

## Learning Highlights
- **Layout Consistency**: Restricting layout dimensions safely using CSS variables for maximum adaptability.
- **Accessible Clipping**: Understanding why `.sr-only` requires precise `clip` properties to satisfy modern assistive standards.
- **Custom Utility Scope**: Writing modular helpers that easily complement any custom design system.
