Pill-style layout button designed with extreme border radius for futuristic product CTA tracks.

## Features
- Pill border radius 9999px\n- Clean stark tech typography contrast\n- Smooth expansion scaling feedback on hover

## HTML Usage
```html
<button class="btn-pill" type="button">Join the Newsletter</button>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-pill-bg` | `#000000` | Core background fill |\n| `--btn-pill-text` | `#ffffff` | Label text color |

## Accessibility Notes
- Exceeds standard 4.5:1 contrast. Easily focusable.
