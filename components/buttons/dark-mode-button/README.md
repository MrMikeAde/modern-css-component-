## Features

## HTML Usage
```html
<div class="dark-mode-wrapper">
  <button class="btn-dark" type="button">Initialize Grid</button>
</div>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-dark-bg` | `#111827` | Inside background core |\n| `--btn-dark-glow` | `#00f0ff` | Cyber glow accent |

## Accessibility Notes
- Requires correct dark mode contexts. Exposes highly visual focus boundaries.

## Browser Support
- All modern browsers.

## Best Use Cases
- SaaS dark schemes, programming tools, developer terminal systems.
