# Underline Hover Button

## Overview
Clean action button with an expanding base underline that expands outward from the center on hover.

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-und-color` | `#1e293b` | Label text color |\n| `--btn-und-line` | `#4f46e5` | Line color |
