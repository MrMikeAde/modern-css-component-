# Ripple Style Button

## Overview
Pure CSS material ripple button that triggers a wave expand overlay effect upon click.

## Features
- Pure CSS click state mapping with active pseudo-class\n- Smooth circle fade animation\n- High performance graphics using scaling mechanics

## HTML Usage
```html
<button class="btn-ripple" type="button">Save Settings</button>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-ripple-bg` | `#0284c7` | Light blue core bg |\n| `--btn-ripple-text` | `#ffffff` | Interactive label color |

## Accessibility Notes
- Keeps original focus management intact while maintaining ripple styling.

## Browser Support
- All modern browsers.

## Best Use Cases
- Material design systems, user settings panels, save-trigger indicators.
