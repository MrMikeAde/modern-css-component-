# Gradient Button

## Overview
Vibrant, moving sunset gradient CTA button that animates background position on hover.

## Features
- Interactive moving gradient layout\n- Beautiful gradient visual depth shadows\n- Subtle hovering push elevations

## HTML Usage
```html
<button class="btn-gradient" type="button">Upgrade Now</button>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-grad-start` | `#ff007f` | Starting gradient color |\n| `--btn-grad-end` | `#7f00ff` | Terminal gradient color |

## Accessibility Notes
- Strong color overlays, clear target indicators.

## Browser Support
- All modern browsers. Uses linear-gradient background shifts.

## Best Use Cases
- Premium payment callouts, upgrade plans, registration pages.
