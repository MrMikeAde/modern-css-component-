# Ghost Button

## Overview
Transparent low-emphasis layout button with subtle background reveal upon hover.

## Features
- Seamless integration into panels\n- Subtle hover background highlights\n- Zero physical boundary lines

## HTML Usage
```html
<button class="btn-ghost" type="button">Cancel</button>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-ghost-text` | `#64748b` | Standard label color |\n| `--btn-ghost-bg-hover` | `rgba(15, 23, 42, 0.05)` | Hover background fill |

## Accessibility Notes
- Exposes standard system interactions without confusing high elements.

## Browser Support
- All modern browsers.

## Best Use Cases
- Dismiss or cancel pathways, subtle dashboard settings buttons.
