# Split Color Button

## Overview
Unique multi-element layout button that sweeps a secondary solid color from left-to-right across its canvas on hover.

## Features
- Clean color sliding sweep transitions\n- Nested text layer with progressive index elevations\n- Exemplary modern corporate tech style

## HTML Usage
```html
<button class="btn-split" type="button">
  <span>Discover More</span>
</button>
```

## CSS Customization
List of CSS Variables you can override locally or in your global variables file:

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `--btn-split-border` | `#1e293b` | Outer border line |\n| `--btn-split-bg-hover` | `#1e293b` | Solid slide background color |
