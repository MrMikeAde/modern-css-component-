# Buttons Category

## Overview
Buttons are crucial interactive triggers that execute user-driven actions. This category features clean, lightweight, accessibility-focused button variants leveraging Modern CSS3 structures (such as custom properties, fluid padding, and modern pseudo-states like `:focus-visible` and `:disabled`).

## Planned Components
1. **Primary Button**: Sleek standard button with seamless hover, active, and focus transitions.
2. **Outline Button**: Bordered action buttons that scale gracefully with background contrast.
3. **Ghost Button**: Text-only buttons suited for low-emphasis triggers.
4. **Interactive States**: Dynamic styles for loading and successfully completed button actions using purely CSS-based loaders and animations.

## Learning Highlights
- **Focus Rings**: Learn to separate hover behavior from keyboard focus utilizing the `:focus-visible` pseudo-class.
- **Micro-interactions**: See how to design smooth transition-duration parameters that don't trigger layout shifting.
- **Logical Properties**: Utilizing `padding-inline` and `padding-block` to support bidirectional content dynamically.
