# Heroes Category

## Overview
Hero sections are the visual gateways to websites and landing pages, designed to captivate visitors instantly. This category features high-impact layouts utilizing CSS Grid, fluid font scales with `clamp()`, and modern background visual treatments.

## Planned Components
1. **Classic Split Hero**: Text and action triggers on one side, paired with responsive image frames on the other, utilizing CSS Grid layout structures.
2. **Centered Minimalist Hero**: Clean, typography-focused layouts using math functions for responsive text distribution.
3. **Immersive Overlay Hero**: Rich image backgrounds paired with high-contrast text overlays optimized with CSS `backdrop-filter`.

## Learning Highlights
- **Fluid Typography**: Integrating `font-size: clamp(2rem, 5vw, 4rem)` to scale text dynamically based on the device viewport.
- **Grids and Gaps**: Utilizing CSS Grid with logical spacing parameters to prevent overlaps.
- **Visual Optimization**: Applying `object-fit: cover` to background assets to guarantee aspect ratios remain elegant.
