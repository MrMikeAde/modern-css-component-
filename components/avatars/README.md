# Avatars Category

## Overview
Avatars visually represent users, entities, or brands. This category features robust circular and rounded image grids, fallback text badges, and group stack layers with integrated CSS status badges.

## Planned Components
1. **Standard Circular Avatar**: Responsive profile containers with high-fidelity focal points.
2. **Text-Fallback Initials**: Automated CSS fallback initials when user photos are missing.
3. **Avatar Stacks**: Horizontal overlay groupings representing collaborative teams.

## Learning Highlights
- **Object Positioning**: Combining `object-fit: cover` and `object-position` to avoid stretching images.
- **Overlapping Layouts**: Building overlapping avatar stacks using negative margin-inline settings instead of manual absolute positioning.
- **Semantic Badges**: Aligning status indicator circles precisely with the avatar using absolute coordinates.
