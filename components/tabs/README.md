# Tabs Category

## Overview
Tabbed systems divide content into distinct views that users can cycle through, maximizing screen real estate. This category implements accessible, pure CSS tab components using semantic markup.

## Planned Components
1. **Classic Navigation Tabs**: Inline tab indicators with smooth sliding underline transitions.
2. **Pill-Style Tabs**: Segmented control panels utilizing flex layouts and contrasting background fills.
3. **Pure CSS Tab Switcher**: Tab controllers utilizing checkboxes, radios, or target hashes to toggle visible container divs.

## Learning Highlights
- **Checked States**: Toggling visible views natively with `:checked` paired with sibling selectors (`~`).
- **Focus Indicators**: Styling selected tabs with high visibility indicators (`aria-selected="true"` or focus outlines).
- **Flex Container Spacing**: Creating scrolling horizontal bars on narrow screens using `overflow-x: auto` and scroll-snapping.
