# Tables Category

## Overview
Tables organize complex relational datasets for efficient scanning. This category introduces responsive, scroll-aware data tables that remain accessible and easy to digest on all viewport sizes without breaking layouts.

## Planned Components
1. **Responsive Data Grid**: Scroll-wrapped tables with pinned columns for seamless side-by-side comparison on mobile screens.
2. **Striped Operational Table**: High-legibility tables with alternating background colors and prominent active hover indicators.
3. **Stacked Mobile Table**: Structured tables that gracefully collapse into distinct individual data cards on narrow screens.

## Learning Highlights
- **Sticky Headers**: Utilizing `position: sticky` and `inset-block-start` to lock headers during long scrolls.
- **Table Layout Control**: Applying `table-layout: fixed` to allocate column widths predictably.
- **Scroll Container Shadows**: Creating visual gradient shadows to indicate horizontal overflow and scrollability.
