# Alerts Category

## Overview
Alert components display critical system-wide feedback, notifications, and status alerts to visitors. This collection offers clean, lightweight alert layouts built with semantic status elements and highly visible icons.

## Planned Components
1. **Banner Alerts**: Full-width top notification banners for high-importance global bulletins.
2. **Inline Notifications**: Clean feedback bubbles (Success, Warning, Info, Error) designed to sit contextually within form steps or content columns.
3. **Floating Toasts**: Off-canvas notification popups with subtle CSS animations.

## Learning Highlights
- **Role Attributes**: Utilizing `role="alert"` and `aria-live` specifications correctly to ensure screen readers immediately identify the update.
- **Color Contrast Guidelines**: Sourcing status background/text pairings that exceed standard contrast requirements.
- **Pure CSS Exit**: Leveraging `:target` or CSS-controlled checkboxes to let users close notifications without JavaScript.
