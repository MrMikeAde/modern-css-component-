# Cards Category

## Overview
Cards are versatile containers designed to display structured content, media, and quick actions. This category showcases modern responsive cards utilizing CSS Grid, Flexbox, Fluid Typography, and CSS Container Queries.

## Planned Components
1. **Article Card**: Complete with featured images, tags, a title, a brief description, and author metadata.
2. **Product Showcase Card**: Focuses on high-contrast pricing indicators, hover-zoom image effects, and checkout triggers.
3. **Container-Query Card**: An advanced card layout that transitions seamlessly from a portrait view to a wide landscape row depending *strictly* on its parent container's width.

## Learning Highlights
- **Container Queries**: Understand why `@container (min-width: ...)` is revolutionary for component-driven UI design.
- **Aspect-Ratio**: Styling flexible media wrappers natively with `aspect-ratio` to avoid layout cumulative shift.
- **CSS Nesting**: Writing highly legible, modern nested stylesheets within the BEM scope.
