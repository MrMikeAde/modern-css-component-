# Badges Category

## Overview
Badges are compact status, metric, or categorizing indicators used to highlight items or label metadata. This category provides clean, modular, and highly custom pill-style tags that support fluid typography and high-contrast environments.

## Planned Components
1. **Pill Badges**: Curved metadata tags representing content categories (e.g., Blog tags).
2. **Count Badges**: Small overlay circles displaying numeric metrics (e.g., Shopping cart item indicators).
3. **Status Indicators**: Micro dot-badges reflecting online, busy, or offline states.

## Learning Highlights
- **Layout Precision**: Using inline-flex layouts to keep badges properly aligned with neighboring texts.
- **Micro-sizing**: Sizing badges with `em` units instead of `px` so they scale proportionally when wrapping elements change font size.
- **High-contrast**: Adding borders using `transparent` styles that automatically surface on high-contrast assistive devices.
