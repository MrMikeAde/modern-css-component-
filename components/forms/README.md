# Forms Category

## Overview
Accessible, performant, and visual forms are fundamental to modern user interfaces. This category contains purely semantic inputs, textareas, checkboxes, radio selections, and custom selectors that emphasize built-in browser validation, focus styling, and error states without relying on JavaScript libraries.

## Planned Components
1. **Interactive Field Wrapper**: Inputs with clean floating labels using CSS `:placeholder-shown` and focus transitions.
2. **Custom Switch / Checkbox / Radio**: Pure CSS visual enhancements over native interactive standard inputs.
3. **Form Row / Validation Group**: Layouts that automatically render success/error aesthetics using the `:invalid` and `:valid` pseudo-classes.

## Learning Highlights
- **Native States**: Designing accessible visual styles around `:disabled`, `:invalid`, `:required`, and `:focus-within`.
- **Contrast Ratios**: Ensuring high-contrast borders and active visual boundaries for inputs.
- **Label Associations**: Pairing `<label for="...">` with input tags properly for screen readers.
