# Pagination Category

## Overview
Pagination splits expansive lists or search results into distinct, manageable page intervals. This category presents structured pagination controls featuring clean alignment, intuitive focus rings, and responsive button layouts.

## Planned Components
1. **Classic Numbered Bar**: Traditional list of sequential pages flanked by Previous and Next controllers.
2. **Rounded Pill Pagination**: High-contrast, minimal pill navigation designed for modern interfaces.
3. **Compact Load-More pagination**: Layout layouts focusing on simple infinite loading design frameworks.

## Learning Highlights
- **Keyboard Navigation**: Ensuring pagination controls are fully tabbable links or buttons.
- **Current Indicator State**: Applying `aria-current="page"` to the active page so screen-readers announce state accurately.
- **Mobile Pruning**: Using CSS media queries to hide mid-sequence page numbers on smaller screens, keeping navigation simple.
