# Progress Category

## Overview
Progress components show the status of a multi-step task or the completion percentage of an operation. This category showcases native, accessible `<progress>` styling alongside custom circular charts and timeline status trackers.

## Planned Components
1. **Semantic Progress Bar**: Styling the native HTML5 `<progress>` element directly to ensure consistent design across browsers.
2. **Circular Progress Indicator**: Stunning, animated progress rings built with pure CSS and SVG variables.
3. **Step-by-Step Progress Tracker**: Sequential timeline lines tracking checkout paths or onboarding wizards.

## Learning Highlights
- **Native Customization**: Styling vendor-specific progress tracks using selectors like `::-webkit-progress-bar` and `::-moz-progress-bar`.
- **SVG Stroke Dash**: Building dynamic circular meters using `stroke-dasharray` and `stroke-dashoffset` controlled via CSS custom properties.
- **Semantic Text Fallbacks**: Providing clear percentage values inside the element markup for legacy screen readers.
