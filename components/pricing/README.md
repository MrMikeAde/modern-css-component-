# Pricing Category

## Overview
Pricing components are key conversion drivers. This category showcases modern pricing tables, comparative plans, and responsive comparison grids that use CSS Flexbox, Grid, and Custom Properties to ensure visual hierarchy and seamless mobile adaptation.

## Planned Components
1. **Tiered Plan Cards**: Classic three-tier model (Basic, Pro, Enterprise) with highlighted features and interactive action buttons.
2. **Tabbed Billing Selector**: Pricing systems with native CSS toggle structures enabling visitors to choose between Monthly and Yearly payment cycles.
3. **Responsive Comparison Grid**: Multi-attribute tables that transform into structured cards on smaller mobile displays.

## Learning Highlights
- **Visual Hierarchy**: Applying subtle CSS shadow designs (`box-shadow`) and scale transformations (`transform: scale()`) to highlight recommended plan tiers.
- **Table Layouts**: Styling structured pricing comparison lists using semantic tabular HTML tags.
- **Dynamic Flexbox Wrapping**: Aligning action cards elegantly regardless of varying card feature-list lengths.
